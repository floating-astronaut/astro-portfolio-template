This is an example blog post. The frontmatter above is validated against the
schema in `src/content/config.ts`.

To add your own posts, drop `.mdx` files in `src/content/blog/`. To render
them, add a `/blog` index page and a `/blog/[slug]` dynamic route — see the
README section **Content collections** for the snippet.

## Markdown works as you'd expect

- Lists
- **Bold**, _italic_, `inline code`
- Code blocks, images, and MDX components

Happy shipping.
